# ミヤマ 完納・EDI連携

トヨタWG共通EDIの「QR読取 出荷案内（初回完納）」画面で明細QRを読み取ると、同じQRを表示している「完納処理待ち」を処理済みにします。

## 導入

1. Chromeで `chrome://extensions/` を開く。
2. 「デベロッパーモード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」を押す。
4. この `edi_completion_link` フォルダーを選ぶ。
5. 完納処理待ち画面とEDI画面を再読み込みする。

拡張機能を更新または再読み込みした場合も、開いている完納処理待ち画面とEDI画面をそれぞれ再読み込みしてください。
専用起動ページは拡張機能の更新時に自動で再読み込みします。

または、`edi_completion_workspace.html` を開き「2画面を開く」を押すと、両画面を左右に配置できます。
右側はトヨタWG共通EDIのログイン画面を開きます。ログイン後、「QR読取 出荷案内（初回完納）」画面へ移動してください。
専用ページから開いた左右のタブは拡張機能内で紐付けられ、直接転送時は右側のEDI画面を優先します。

## 使用条件

- 完納処理待ち画面は1タブだけ開く。
- EDI画面は `outboundQrAll.do` のQR入力画面を使用する。
- QR入力の確定キーはEnterを推奨する。
- EDIに入力されたQRと完納処理待ちのQRが完全一致した場合だけ処理済みにする。
- EDIの「出荷案内実行」は自動操作しない。
- 処理記録の `method` には `edi_link` を保存する。

EDI画面右下に「完納・EDI連携 準備完了」が表示されれば待機状態です。

## 直接転送の試作

完納処理待ち画面の「EDIへ1件転送（試作）」を押すと、表示中の先頭QRをEDIの最初の空欄へ直接入力します。読取情報を確認後、EDI画面の「出荷案内実行」を押すと問合せ情報が反映されます。
表示中のQRカードをクリックした場合は、そのQRをEDIの最初の空欄へ直接入力します。拡張機能が有効な間は、QRクリックだけで処理済みにはしません。
EDI入力欄への転送に成功したQRは現在の完納待ち画面から隠し、次のEDI対象QRを表示します。DB上の処理済み記録は変更しません。
転送時は `[)>` 形式から、共通EDI画面が要求する9項目のコロン区切り形式を生成します。項目順は、納入先企業・納入先工区・受入・出荷元企業・出荷元工区・納入指示日・納品書番号・便2桁＋ページ2桁・帳票区分2桁です。複合項目 `2L` は固定長（企業10桁＋工区5桁）で分割し、ページは最初の明細番号 `K` から取得します。
`[)>` で始まり、共通EDIの見出しDI（6V・2L・16D・10K）を持つQRだけを対象とし、それ以外は一覧内で読み飛ばします。
この変換は共通EDI画面の保存ソースを基にした試作です。転送後は表示された納入指示日と納品書番号を確認してから操作してください。

- 試作転送では完納処理済みに更新しません。
- 「出荷案内実行」は自動で押しません。
- EDIの読取情報が正しく表示されることを目視確認してください。
